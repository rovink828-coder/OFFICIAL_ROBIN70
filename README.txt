OFFICIAL_ROBIN1M E ADMIN VERSION

Files:
- index.html = customer/store page
- admin.html = admin panel

How to use:
1. Upload both files to the same GitHub Pages repository.
2. Open /admin.html for the admin panel.
3. Default password is admin123. Change it in admin.html before publishing.
4. Edit UPI and package names/prices, then Save Settings.
5. Open index.html (your main site) and refresh.

IMPORTANT:
This version stores settings/orders in the browser's localStorage. That means the admin changes are NOT shared with other visitors/devices. For a real multi-user admin system, a backend/database and authenticated server-side admin login are required.
